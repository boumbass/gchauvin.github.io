Règles de confidentialité de gog-perso

Usage : gog-perso est un outil personnel utilisé uniquement par son propriétaire, pour ses propres comptes Google.

Données consultées : les données Google (messages, agenda, fichiers) sont lues ou modifiées uniquement à la demande du propriétaire, depuis son ordinateur.

Stockage : les jetons d'accès sont conservés localement, dans le gestionnaire d'identifiants du système d'exploitation. Aucune donnée n'est envoyée vers un serveur de l'application : il n'en existe pas.

Partage : aucune donnée n'est vendue, partagée ni transférée à des tiers. L'utilisation des données reçues des API Google respecte les règles relatives aux données utilisateur des services API Google, y compris les exigences d'utilisation limitée.

Révocation : l'accès peut être retiré à tout moment sur myaccount.google.com/permissions.
